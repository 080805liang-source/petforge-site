# PET FORGE illustrated chat skins

150 original PNG message frames, used alongside the 50 classic presets in chat-themes.json.
25 catalog categories / 200 presets total. Illustrations are built from original geometric drawings, with animal silhouettes, corner characters, flowers, ribbons and other motifs.

The user's QQ personalization screenshots were visual references for categorized browsing, decorated corners and shaped message bubbles. QQ artwork, logos, paid assets and character illustrations are not included.

Reference browsing: https://vip.qq.com/ and https://kenney.nl/assets/ui-pack (CC0 UI pack studied for scalable UI framing; no pack assets are bundled).

Web and Windows use the same selected PNG with nine-slice scaling so messages can grow with their contents. Export includes only the chosen illustrated asset.
