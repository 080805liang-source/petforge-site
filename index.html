3D Jump

页面切换像从工作台跳进生成器。

导航跳转时，预览桌面会产生轻微 3D 翻转；用户能感到自己正在进入一个制作空间，而不是阅读普通说明页。

Flow

用户只需要四步

  1. 上传图片选择自己喜欢的角色或宠物图。
  2. 调整外观确认大小、气泡和桌面预览效果。
  3. 添加功能勾选浏览器、游戏、文件夹、提醒等快捷入口。
  4. 生成桌宠导出配置，后续连接打包服务生成可运行程序。

Notes

第一版边界

网页能直接运行桌宠吗？

不能。网页负责定制和生成配置，真正的 Windows 桌宠需要下载到电脑本地运行。

现在能生成什么？

可以上传图片、实时预览、配置菜单，并在浏览器里生成 Windows zip 程序包。

下一步补什么？

后续可以继续升级为 exe 打包、账号作品库、在线模板市场和插件系统。
