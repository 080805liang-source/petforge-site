下载与 Windows 安全

点击“生成”后没有看到下载文件？

先确认已上传图片、已登录，且会员有效或账号还有可用次数。生成完成后，浏览器会下载一个 ZIP 文件。

打开 Edge 或 Chrome 的下载列表，检查是否被浏览器暂停；如提示允许多个文件下载，请允许本站下载。仍没有文件时，清除失败下载记录后刷新页面再试，并检查系统“下载”文件夹。

下载的 ZIP 怎么打开？

在文件管理器中右键 ZIP，选择“全部解压”，再进入解压后的文件夹双击 `PetForge.exe`。不要在压缩包预览窗口里直接运行。

请保留同一文件夹里的 `PetForge.exe`、`config.json` 和 `assets` 文件夹，不要只移动 EXE。这个版本是便携包，不是安装向导。

Windows 显示“未知发布者”或 SmartScreen 提示怎么办？

目前公开桌宠包尚未使用受信任的代码签名证书，因此 Windows 可能提示无法验证发布者。这个提示本身不能证明文件有毒，也不能证明文件一定安全。

只从 PET FORGE 官方网站下载，并可先用 Microsoft Defender 扫描文件。若不确定来源或不放心，请取消运行；不要关闭 Defender、SmartScreen，也不要添加排除项来绕过提示。

PetForge.exe 双击后没有窗口或马上退出？

确认 ZIP 已完整解压，并且 EXE、配置文件和 `assets` 仍在一起。把整个文件夹放在本机一个固定位置（例如“下载”或“桌面”），再启动一次；不要从压缩包、网盘预览或临时目录运行。

如果仍退出，请邮件附上 Windows 版本、启动步骤和错误截图。不要把账号密码、邮箱验证码或个人文件发来。

注册、登录与会员码

如何注册和接收验证码？

注册时填写自己的邮箱，点击“发送验证码”，再输入邮件中的 6 位验证码和至少 8 位密码，并再次确认密码。收不到邮件时请检查垃圾邮件，等待 60 秒后可重发。手机号注册暂未开放，已有手机号账号仍可使用密码登录。

登录时也要选择注册时使用的同一身份方式。邮箱和手机号不要互相替代尝试。

忘记密码了怎么办？

打开找回密码，填写注册邮箱，接收 6 位验证码后设置新密码。密码更新后，需要在所有设备重新登录；会员权益保留。已有手机号账号如未绑定邮箱，请联系支持核实账号。

验证码没有收到，应该怎么排查？

请检查邮箱地址拼写、垃圾邮件和广告邮件文件夹。验证码 10 分钟内有效，发送后等待 60 秒可重新获取；请使用最新一封邮件的验证码。

如果页面明确提示账号服务未配置或暂时无法连接，稍后再试仍不行，请邮件反馈发生时间和提示截图；不要在邮件里提供验证码或密码。

注册时提示密码不一致或密码无效？

密码至少 8 位；注册表单中的“密码”和“再次确认密码”必须完全一致。注意检查输入法、前后空格和大小写，再重新输入两遍。

怎么兑换会员码？

登录后点击顶部账户入口，输入已获得的会员码并点击“兑换会员码”。兑换成功后，权益立即加入当前账号。

会员码由站外渠道交付，本站不收款、不展示支付二维码。每个码只能兑换一次，请确认登录的是你自己的账号。

会员码无效或兑换后权益没有变化？

检查会员码是否完整、是否已经兑换或被停用。刷新账户后仍有问题，请邮件提供登录邮箱、错误提示和会员码最后两组字符，请勿发送完整会员码。

会员有效期和续期怎么算？

会员从兑换时开始计时，有效期内不限生成次数。提前续期会接在原有效期后，过期后续期则从兑换时重新计算。已有使用次数仍保留，会员有效期内不会扣减。

图片与桌宠制作

如何自动去掉图片背景？

上传图片后默认自动抠出主体，预览和生成包使用同一张透明 PNG。纯色背景优先快速处理，复杂照片会在浏览器内识别主体；首次使用需要下载本站的识别文件。

抠图只移除轮廓外的背景，角色内部保留原图颜色和不透明度。预览默认以 100% 不透明度显示；风格滤镜仅在你主动选择时应用。

白色身体不会按颜色整片删除。若有漏抠或边缘不理想，可在“图片背景”里改选“智能识别主体”；选择“保留原图背景”即可恢复。多人、遮挡和接近背景色的细节可能需要更换清晰图片。

如何切换阴影和动态模式？

创作台默认静态、无阴影。可勾选“柔和阴影”或“动态桌宠”，再生成桌宠包；运行后也可在右键菜单切换并保存。已下载的旧版本需要重新生成下载。

动态模式以 120 帧/秒为目标，实际流畅度取决于电脑性能和屏幕刷新率。静态模式保留拖动、气泡和快捷入口。

支持什么图片？图片太大或预览失败怎么办？

支持 PNG、JPG/JPEG 和 WEBP。透明背景的 PNG 通常更适合桌宠。大图片会占用较多浏览器内存；如果预览卡住，可以先把图片缩小或压缩，再用新版 Edge 或 Chrome 重试。

桌宠创作页的预览和生成在当前浏览器中处理图片；只有你主动发布到创意工坊时，图片和作品资料才会上传并公开展示。

“生成”按钮不可用或提示没有次数？

依次检查图片、预览和登录状态，再确认会员有效或有剩余次数。没有使用权益时，请从账户入口兑换会员码。

如果登录状态反复消失，刷新页面重新登录；如提示账号服务无法连接，先确认网络，再稍后重试。

生成提示桌宠运行核心下载失败？

生成 ZIP 时，网页还需要从本站读取桌宠运行文件。刷新到最新版后重试，并确认网络没有拦截本站文件下载。

如果仍显示 HTTP 错误或“文件不完整”，请邮件提供错误提示、浏览器版本和发生时间；不要反复生成消耗次数，先联系支持确认。

设置怎么保存？刷新后还会保留吗？

下载的桌宠 ZIP 包含当前透明图片和全部配置。也可点击“一键发布到创意工坊”公开保存作品，再从工坊的“查看配置”载入编辑。刷新前请先下载或发布，未保存的编辑状态不会自动备份。

怎样分享作品，让别人直接使用？

在创作台设置好图片、台词、动画和快捷入口，点击“一键发布到创意工坊”。别人点击作品的“直接使用”即可载入同一张图片与全部设置，并按当前账号的使用权益生成桌宠。整个网站使用同一套登录账号。

作品里的快捷入口会一起分享；其他电脑的软件安装位置可能不同，可在“查看配置”中调整。创作者可以在自己的工坊作品下取消分享。

为什么旧桌宠有白色背景板？

旧版本的兼容显示模式会显示底板。请退出旧桌宠，从最新版网站重新生成并完整解压 ZIP，再运行新包中的 PetForge.exe。新版默认透明窗口；图片本身如有背景，请先在网页里抠图。

快捷入口没有打开目标软件？

网址类型适合网站；软件类型需要目标电脑已安装对应程序；文件或文件夹路径必须在那台电脑上存在。检查路径、应用协议和安装位置，再重新生成桌宠包。

你电脑上的本地路径不会自动适用于其他用户的电脑；分享桌宠时请优先使用网址，或说明对方需要自行调整的路径。

网站、隐私与其他问题

我上传的图片会被网站保存吗？

制作页的预览和桌宠包生成在浏览器本地处理图片。若你主动把作品发布到创意工坊，作品图片、标题、说明和配置会上传以供公开浏览；请勿发布含私人信息或未经授权的图片。

封面语言切换后会保存吗？

语言选择会保存在当前浏览器，下次打开本站会继续使用。切换只改变网站界面文字，不会翻译你自己输入的桌宠名称、台词或上传图片。

提交问题时，邮件里最好写什么？

请写清楚所在页面、操作步骤、预期和实际结果，并附浏览器或 Windows 版本与截图。会员码问题只提供尾号。

请勿发送密码、验证码、完整会员码、私人照片或其他敏感资料。
