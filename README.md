# PET FORGE

公开访问地址：https://080805liang-source.github.io/petforge-site/

这是一个用于创建个人 Windows 桌宠的网站。`index.html` 是独立的三维小猫封面；点击“制作我的桌宠”进入 `creator.html`，上传自己的图片，再预览并生成个人桌宠。原来的 `#studio` 分享链接和工坊模板链接会转到制作页。

封面是一只本地程序建模的圆脸虎斑幼猫：三维毛发、蓝色虹膜、胡须、内耳、爪垫，以及坐姿、行走、扑抓、落地和眨眼。逗猫棒手柄直接跟随指针，细绳和羽毛使用弹簧摆动；手机支持轻触。Three.js 0.186.1 随站点部署，不依赖 CDN 或外部模型下载。系统开启减少动态效果时停止闲置动作、缩短羽毛摆动，主动指针互动仍可使用。

验证：`npm run test:cat`（移动、扑跳、暂停、边界和光标弹簧），以及封面/制作页跳转、桌面和手机布局检查。当前是风格化三维幼猫，并非用户照片的写实三维重建。旧版未使用的猫素材授权仍记录在 `assets/models/ATTRIBUTION.md`。

当前能力：

- 3D 创作台与无预设角色的首次状态
- 图片上传与实时预览
- 桌宠名字、点击台词、大小、透明度、状态、动画、气泡、初始位置调整
- 用户自定义多个快捷入口
- 导出制作配置 JSON
- 在浏览器端生成包含 Windows 应用的 zip 桌宠包

当前网站生成的是便携 ZIP，包含 `PetForge.exe`，解压后双击即可运行，不需要安装 Python。由于这个 ZIP 内的 EXE 目前没有受信任的发行者签名，其他用户首次运行可能看到 Windows SmartScreen 提示；网站不能合法替所有用户关闭该提示。

面向所有用户的免费公开分发正在准备 Microsoft Store MSIX 路线：商店认证后会自动重新签名。清单模板、打包脚本和 GitHub Actions 工作流见 `store/`。发布前仍需要站长本人完成免费的 Microsoft 开发者账号身份验证、保留应用名称并提交商店审核。

网站现在同时支持 PWA：在 Edge 或 Chrome 打开网站后，点击地址栏的安装按钮，或点击页面右上角的“安装应用”，即可把 PET FORGE 安装成独立窗口。PWA 负责创作台和账号功能；真正悬浮在 Windows 桌面的宠物仍需要独立客户端。

当前使用方式已改为按次计费：注册/登录后，每生成一次桌宠 ZIP 消耗 1 次；扫码支付 9.90 元可购买 3 次。支付宝二维码需要将站长自己的收款码保存为 `assets/alipay-qr.png` 后才会显示。订单创建后由管理员确认收款，不能仅凭前端按钮自动增加次数。

账号注册分为两种独立方式：邮箱注册需要邮箱验证码，手机号注册需要短信验证码；注册时两次密码必须一致。验证码服务未配置时，页面会显示明确错误，不会创建未验证账号。
