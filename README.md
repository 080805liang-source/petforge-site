# 桌宠工坊网站

这是一个网站原型，用于展示并生成“上传图片并定制桌面宠物”的 Windows 程序包。

只看页面：

1. 双击 `index.html`
2. 或用任意浏览器打开 `index.html`

生成 Windows 桌宠程序包：

1. 打开网站。
2. 上传图片并配置桌宠。
3. 点击 `生成 Windows 程序包`。
4. 浏览器会直接生成 zip 下载，不依赖本机后端。

手机访问：

1. 手机和电脑连接同一个 Wi-Fi。
2. 在手机浏览器打开电脑局域网地址，例如 `http://192.168.1.111:8765`。
3. 如果手机打不开，检查 Windows 防火墙是否允许 Python/8765 端口访问专用网络。

当前能力：

- 首页 3D 桌面宠物封面
- 图片上传与实时预览
- 桌宠名字、点击台词、大小、透明度、状态、动画、气泡、初始位置调整
- 快捷菜单功能勾选
- 导出制作配置 JSON
- 在浏览器端生成 Windows zip 桌宠程序包

当前生成包使用 Python/Tkinter 运行，解压后双击 `run_desktop_pet.bat`。
