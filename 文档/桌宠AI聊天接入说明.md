# 桌宠 AI 聊天接入说明

更新：2026-11-10。免费 AI 的网页、Windows 桌宠和服务端额度控制已接入；真实模型调用的验收状态以本次发布记录为准。

网页已取得真实豆包回复；新版 Windows 打包程序被 Defender 拦截，暂不能确认误报，当前已暂停桌宠下载且不扣生成次数。桌面相关使用说明在解决安全检测问题后适用，不要关闭系统防护。

完整使用与配置说明见 [CHAT-SETUP.md](../CHAT-SETUP.md)。

## 用户怎么使用

创作台选择「免费 AI（工作室赠额）」，登录已验证的网站账号后即可聊天预览。下载的新桌宠会携带仅能聊天、30 天有效且可撤销的绑定，右键「展开聊天」即可使用。过期后可在桌宠内登录网站账号续绑，不需要用户提供模型 Key。旧版桌宠需要重新下载。

## 免费额度

| 范围 | 限制 |
| --- | --- |
| 每个已验证账号 | 每日 20 次、每分钟 3 次 |
| 全站 | 每日 200 次 |
| 重置时间 | 北京时间每日 00:00 |
| 首期累计预算 | 保守预占 100000 token，跨天不恢复 |
| 单条提问 | 最多 1000 字符 |
| 上下文 | 最近 6 条，合计最多 1800 字符 |
| 单次输出 | 最多 256 token |

网页和桌宠显示账号今日剩余次数；同一账号的多个设备共用额度。全站次数或共享赠额先用完时暂停服务，20 次是个人上限，不保证每个账号每天都能用满。请求在发送前通过数据库事务预占；超时和失败可能已消耗上游赠额，不返还预占次数，也不自动重试。

## 工作室如何控制费用

已选豆包轻量文本模型，固定官方接口，禁用深度思考和工具调用，不联网搜索或执行电脑命令。必须同时保留方舟「安心体验」开启和服务端累计预算限制；赠额耗尽暂停，未授权充值。协作奖励计划不是本方案的一部分。

工作室 Key 仅放在服务端，绝不进入公开网页、作品或桌宠 ZIP。下载包仅含独立聊天凭据，首次启动导入当前 Windows 用户加密存储，并移除解压目录中的明文绑定；原始 ZIP 仍需保持私密。修改网站密码或在创作台点击「取消全部桌宠绑定」会使原绑定失效。

聊天消息会经工作室服务端转交豆包处理，默认不保存聊天正文。基础陪伴模式仍为本地离线回复，不消耗 AI 次数；用户自带 Key 模式独立计费，由其自己的服务商处理。
