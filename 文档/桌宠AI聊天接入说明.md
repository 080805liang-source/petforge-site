# 桌宠 AI 聊天接入说明

更新：2026-11-09。当前状态：方案已准备，尚未接入模型，现有桌宠仍使用本地回复库。

## 要实现的体验

用户右键桌宠选择「AI 聊天」，在宠物聊天窗口里提问，回复同时显示在对话窗口和桌宠气泡。支持日常问答、文字整理、学习解释和简单计划；当前回复库作为独立的离线聊天模式保留。AI 不直接执行命令、读取文件或操作用户电脑。

用户不需要购买模型服务，也不需要提供自己的 API Key。工作室提供有上限的公共额度。额度用完明确显示「今日 AI 免费额度已用完」，提供本地聊天入口，不伪装成 AI 继续回复。

## 平台建议与费用边界

优先试用火山方舟的豆包文本模型，模型型号以实际控制台可用项为准。官方目前提供免费推理试用额度；适用账号可开启「安心体验模式」，仅消耗赠额，接近用尽时停止服务。它是有限额度，不能宣传永久免费、无限使用。资格、余额、过期时间和是否已开通付费服务必须在本人控制台核实。

DeepSeek 也可以作为替代，官方 API 需要 API Key，并有单独的模型价格。免费聊天官网不代表可免费调用 API，也不能通过抓取个人聊天网页替代官方接口。

本轮没有创建云服务、调用模型或启用付费。未来如需要充值或付费，先确认具体金额和预算再执行。网站上的免费次数限制不能单独保证云平台账单为零；必须同时用平台的免费模式/服务停用能力兜底。

## 你需要准备的内容

1. 打开 [火山方舟控制台](https://console.volcengine.com/ark)，登录你自己的账号。
2. 查询账户是否可开启「安心体验模式」。确认所选模型的免费余额及有效期，先不启用付费推理。
3. 在 API Key 管理创建供桌宠聊天使用的独立 Key，记录所选模型 ID 或推理接入点 ID。
4. 配置时使用平台的服务端密钥管理/环境变量，不在聊天中发送 Key，不把它放入网页 JS、Git 仓库、公开作品配置、下载 ZIP 或桌宠 EXE。

准备好后只需告诉我「已准备好 API Key」，再通过安全的本地文件或控制台方式配置。无需提供登录密码。

## 建议的首批额度

| 范围 | 建议试运行上限 | 达到后行为 |
| --- | --- | --- |
| 每个已验证账号 | 每日 20 次、每分钟 3 次 | 停止该账号的 AI 调用 |
| 全站 | 每日最多 200 次 | 当天所有用户停止调用 |
| 全站累计 token 预算 | 按平台实际赠额设置，预留安全余量 | 累计预算用完即关闭，不因跨天恢复 |
| 单条提问 | 最多 1000 字符 | 提示缩短问题 |
| 上下文 | 最多最近 6 条，合计最多 4000 字符 | 裁剪旧上下文 |
| 单次输出 | 最多 512 token | 截止本次回复 |
| 超时 | 20 秒 | 不自动重试，避免重复计费 |

这些是可调整的建议值，尚未配置或上线。API 超时也可能已经消耗额度，不能假设失败必定免费。

## 接入结构

```text
桌宠聊天窗口
    ↓ 登录或绑定当前站内账号
工作室服务端 /chat
    ├─ 身份校验、单用户限流
    ├─ 全站次数与累计 token 预算，事务预占
    ├─ 固定模型、固定请求地址、输出长度上限
    ↓ 仅服务端持有 API Key
豆包官方 API（或明确选用的 DeepSeek API）
    ↓ 纯文本回复
宠物聊天窗口与气泡
```

复用现有 CloudBase 用户体系，不能仅凭客户端上报的 userId、设备 ID 或可分享的作品 ID 扣免费额度。桌宠需通过浏览器完成本人登录并领取短期、可撤销、只允许聊天的凭据；独立凭据仅保存在本机，不写回公开工坊作品。旧桌宠需重新下载新版才能出现 AI 对话入口。

全站额度使用数据库事务，在发给模型前先预占，防止并发突破上限；累计 token 预算须按所选模型的分词方式估算并保守预占输入与最大输出，完成后再按供应商 usage 对账。用户级次数、防刷和累计预算都在服务端执行，不能只靠网页按钮禁用。不能让用户自由传入模型、上游 URL、system 提示词或工具调用。

聊天内容发送前告知用户会转交所选模型平台处理。默认只在窗口内保留短上下文，不将原始聊天写入运营日志。只记录账号摘要、请求计数、token 用量和错误类型；模型返回内容作为纯文本展示，避免脚本注入。

## 上线前验收

- 真实账号在桌宠内问答成功，界面显示所用模型；本地回复模式有明确区分。
- 匿名、过期、撤销凭据均不能调用；用户 A 不能使用用户 B 的额度。
- 并发触发用户上限、全站上限和累计预算时都不会超额调用。
- 免费体验额度用完/接口拒绝/超时后给出真实提示，不自动切到付费供应商。
- ZIP、EXE、前端脚本和公开作品中均没有模型 Key；日志不含 Key、会话凭据或原始聊天。
- 新 EXE 重新构建后同步更新网站固定文件大小、SHA-256 和运行核心下载地址，并实际下载生成验证。
